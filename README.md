## Featured Projects

> Click **Live** to try the deployed ones.

### 🔍 [Lens](https://github.com/AyushNeedsCaffeine/Lens) · [Live](https://lens-3fzs.onrender.com/)
*Watch Less. Understand More.* Turns a YouTube link or a local video/audio file into a transcript, summary, action items, key decisions, open questions, and a RAG chatbot you can ask follow-up questions against. English via Whisper, Hinglish via Sarvam AI, and long recordings are handled with chunking and map-reduce summarization.

**Tech Stack:** Python • FastAPI • Whisper • Sarvam AI • LangChain • Mistral • ChromaDB • HTMX

---

### 🍳 [QuickChef](https://github.com/AyushNeedsCaffeine/QuickChef) · [Live](https://quickchef-qf47.onrender.com/)
Tell it what you want to cook and get the recipe, the groceries, and a filled cart. An AI agent researches and scales the recipe, then deterministic matching turns ingredients into real grocery packs. Includes human-in-the-loop cart review, AI custom dishes, a daily quota guard, and a 77-case golden eval suite.

**Tech Stack:** Python • FastAPI • LangGraph • Groq • LangSmith • pytest

---

### 🧭 [Atlas](https://github.com/AyushNeedsCaffeine/Atlas) · [Live](https://atlas-qnwy.onrender.com/)
An AI travel agency built as a multi-agent system. Give it a source, destination, budget, days, and dates; a Supervisor coordinates specialist agents for flights, hotels, weather, and itinerary, with input guardrails and human approval before the plan is final.

**Tech Stack:** Python • FastAPI • LangGraph • MCP • Docker

---

### 🚽 [Swachhaalay](https://github.com/AyushNeedsCaffeine/Swachhaalay)
A low-cost, retrofit-friendly smart washroom: an ESP32-based IoT system that monitors air quality, detects occupancy with dual cross-checking sensors, and disinfects automatically after use, never while occupied. The ML pipeline estimates the disinfectant tank level with no physical sensor (virtual sensing), flags air-quality anomalies, and clusters usage patterns for predictive maintenance, all behind a Streamlit dashboard. Built on a physics-informed synthetic dataset, with a paper draft and patent draft in the repo.

**Tech Stack:** ESP32 • Python • scikit-learn • cuML • Streamlit • Plotly • pytest
